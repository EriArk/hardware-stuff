LET’S GET YOU SET UP

Install your book server

We’ll prepare the required components and start your library. No account or setup key needed here.

Server files and settings go here. Books and accounts are kept in Docker’s persistent storage.

Advanced settings

The server will be available on your local network. Existing installations keep their saved settings.

Missing components are installed automatically. Your operating system may ask for permission or a restart. Docker Desktop may show its terms.

READY FOR YOUR FIRST BOOK

Your server is ready.

Open the portable OctoFox Companion browser. It will find this server and display its setup page.

Create your owner account there, then add your books. This installer can now be closed; the server keeps running.
