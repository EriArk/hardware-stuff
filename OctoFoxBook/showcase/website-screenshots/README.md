# Website screenshots

Nine real interface screenshots captured on October 10, 2026. English UI.

- `png/reader/`: unaltered 540 x 960 framebuffer captures from a physical AbyssBook running 0.21.0-alpha11. These are screen pixels, not photographs of the e-ink panel or hardware renders.
- `png/library/`: the running OctoFox Library with original sample stories in a separate demonstration account. Desktop captures are 2880 pixels wide; phone captures are 860 pixels wide. Browser scale is 2x.
- `webp/`: lossless WebP equivalents at the same resolution, ready for a website. Prefer these for page images; keep PNG for editing.
- `preview.jpg`: contact sheet for choosing images. Use the separate images for publication.
- `manifest.json`: captions, dimensions, provenance and PNG checksums.

Library screenshots show the real application, not the older presentation prototype. Phone images are browser viewport captures, not evidence of a physical phone test. No address bars, deployment domains, passwords, tokens or personal accounts are included. The visible showcase-reader name belongs to the disposable demonstration account.

The sample story The Lighthouse Notebook was written for this screenshot set. No application UI elements were painted over or substituted. The temporary sample book was removed from the reader after capture.
