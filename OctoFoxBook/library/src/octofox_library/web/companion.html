Первый аккаунт станет администратором. Позже вы сможете пригласить других читателей.

Где взять ключ?

На компьютере с установленной библиотекой, из папки установки выполните:

python tools/manage.py setup-key

Ключ подтверждает, что вы владелец установки. После первого запуска он больше не нужен.

    ДОМА И В ДОРОГЕ

    Подключение

    Открывайте свою библиотеку с удобного устройства.

    01 · АДРЕСА БИБЛИОТЕКИ

    Где вас найти

    Добавьте адрес сервера в домашней сети или свой HTTPS-домен. Изменение разрешает вход по адресу; саму сеть оно не перенастраивает.

    Основной адрес установки

    Один адрес в строке, не более восьми. Основной адрес останется доступен.

    В домашней сети

    Как открыть с другого компьютера

    Узнайте IP компьютера с библиотекой в настройках сети и добавьте его выше. Адрес контейнера Docker для этого не подходит.

    Если порт открыт только локально, измените строку в файле .env в папке установки:

    OCTOFOX_BIND_ADDRESS=0.0.0.0

    Затем примените настройку на компьютере с библиотекой:

    docker compose up -d --no-deps library

    Разрешите этот порт в брандмауэре для домашней сети. Перезапуск завершит текущие сеансы — после него войдите снова.

    02 · ВНЕШНИЙ ДОСТУП

    За пределами дома

    Узнайте, с какого IP сервер выходит в Интернет. Он может принадлежать VPN или провайдеру с общим адресом.

    По нажатию сервер обратится к ipify. Данные аккаунтов и книг не передаются.

    Найденный IP не подтверждает входящие подключения. Для прямого доступа нужны настройка роутера и HTTPS; при CGNAT может понадобиться туннель.

    НОВЫЙ АККАУНТ

    Пригласите читателя

    Передайте ему логин и пароль лично. Письмо автоматически не отправляется.

    Читатель сможет загружать и читать свои книги. Управление аккаунтами останется у администратора.

    АККАУНТ

    Изменить пароль

    Пароль изменится и для входа в библиотеку. Открытые сеансы чтения завершатся; книги и прогресс сохранятся. После смены своего пароля войдите заново.

    Доступ к библиотеке

    Отключение завершит сеансы OctoFox и запретит чтение и вход. Книги и прогресс останутся на месте; доступ можно включить снова.

    YOUR LIBRARY, YOUR ADDRESS

    Connect your domain

    These illustrations are diagrams, not screenshots of the Cloudflare dashboard. Menu names follow the official guide.

    Prepare your domain

    In Cloudflare, go to Domains → Onboard a domain and add your root domain. Review the DNS records for your website and email, then set the assigned Cloudflare nameservers at your registrar. Wait for Active status.

    Already active in Cloudflare? Continue to the next step. Choose a separate subdomain for your library.

    Enter just the hostname, without https:// or a path. This is a preview; it does not change any settings.

    How to add a domain ↗

    Connect your server to Cloudflare

    Open Networking → Tunnels → Create a tunnel. Name it, choose the server operating system and run the supplied connector installation command on the computer hosting your library.

    Wait for the tunnel to connect. Its token stays on your server; Companion does not need it.

    Keep the server and connector running. A tunnel does not require opening the library port on your router.

    Point the address to your library

    In the tunnel, select Routes → Add route → Published application. Select your root domain and library subdomain. Leave Path empty.

    Copy the displayed Service URL into the route and save it. The public address uses HTTPS; the internal library address uses HTTP.

    Preserve the original Host. Under Additional application settings, do not set HTTP Host Header to localhost.

    Allow the new address in Companion

    Add the HTTPS address to Additional addresses and click Save addresses. This allows access through the domain while keeping your previous address available.

    The button below only fills in the form. You save it separately.

    Check over mobile data

    In the connection check, select the saved HTTPS address and create a QR code. Turn off Wi-Fi on your phone and scan it with the camera. Wait for confirmation on the phone and in Companion.

    Then open the library through your domain, sign in and try reading and narration. The QR code checks that this installation is reachable; it does not sign you in.

    If the connection does not work
    • Domain not found: check the domain status and the DNS record for your chosen subdomain in Cloudflare.
    • Error 502: check that the library is running and its Service URL is reachable from the connector computer or container.
    • Access denied: check the saved HTTPS address and make sure Host is not overridden.
    • QR is not confirmed: generate a new code, check the selected address and turn off Wi-Fi on your phone.
