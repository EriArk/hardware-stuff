ПЕРВЫЙ ЗАПУСК

Настроим библиотеку

Первый аккаунт станет администратором. Позже вы сможете пригласить других читателей.

Где взять ключ?

На компьютере с установленной библиотекой, из папки установки выполните:

docker compose exec library cat /data/companion-setup-key

Ключ подтверждает, что вы владелец установки. После первого запуска он больше не нужен.

От 8 символов. Этот логин и пароль подойдут и для чтения.
