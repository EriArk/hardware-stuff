ПЕРВЫЙ ЗАПУСК

Настроим библиотеку

Первый аккаунт станет администратором. Позже вы сможете пригласить других читателей.

Где взять ключ?

На компьютере с установленной библиотекой, из папки установки выполните:

docker compose exec library cat /data/companion-setup-key

Ключ подтверждает, что вы владелец установки. После первого запуска он больше не нужен.

От 8 символов. Этот логин и пароль подойдут и для чтения.

    Подключение

    Открывайте свою библиотеку с удобного устройства.

    01 · АДРЕСА БИБЛИОТЕКИ

    Где вас найти

    Добавьте адрес сервера в домашней сети или свой HTTPS-домен. Изменение разрешает вход по адресу; саму сеть оно не перенастраивает.

    Основной адрес установки

    Один адрес в строке, не более восьми. Основной адрес останется доступен.

    В домашней сети

    Как открыть с другого компьютера

    Узнайте IP компьютера с библиотекой в настройках сети и добавьте его выше. Адрес контейнера Docker для этого не подходит.

    Если порт открыт только локально, измените строку в файле .env в папке установки:

    OCTOFOX_BIND_ADDRESS=0.0.0.0

    Затем примените настройку на компьютере с библиотекой:

    docker compose up -d --no-deps library

    Разрешите этот порт в брандмауэре для домашней сети. Перезапуск завершит текущие сеансы — после него войдите снова.

    02 · ВНЕШНИЙ ДОСТУП

    За пределами дома

    Узнайте, с какого IP сервер выходит в Интернет. Он может принадлежать VPN или провайдеру с общим адресом.

    По нажатию сервер обратится к ipify. Данные аккаунтов и книг не передаются.

    Найденный IP не подтверждает входящие подключения. Для прямого доступа нужны настройка роутера и HTTPS; при CGNAT может понадобиться туннель.

    Подключить через Cloudflare
    1. Добавьте свой домен в Cloudflare, выберите поддомен библиотеки и сохраните его HTTPS-адрес в форме слева.
    2. В панели Cloudflare откройте Networking → Tunnels и создайте туннель. Установите коннектор на компьютер с библиотекой командой, которую покажет Cloudflare.
    3. В туннеле откройте Routes → Add route → Published application и выберите этот поддомен.
    4. Для коннектора, установленного на самом компьютере, укажите Service URL:Для коннектора в той же Docker-сети — http://library:8080. Сохраняйте исходный Host; переопределять его на localhost не нужно.
    5. Сохраните маршрут и откройте ссылку проверки ниже с другого подключения.

    Токен туннеля вводится только при установке коннектора. Companion его не запрашивает.

    03 · ПРОВЕРКА ПОДКЛЮЧЕНИЯ

    Доходит ли запрос

    Ссылка подтвердит, что выбранный адрес ведёт именно в эту установку. Для проверки извне откройте её на телефоне с выключенным Wi-Fi.

    Открыть проверку ↗

    Отметка подтверждает запрос из открывшего ссылку браузера. Его сеть Companion автоматически не определяет.
