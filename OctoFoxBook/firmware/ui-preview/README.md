# AbyssBook visual preview

Two static Home concepts for the non-touch LILYGO 4.7-S3 H716 reader:
**bookish** and **fantasy**. They share fictional book content and layout so the
comparison focuses on visual treatment. This is a temporary visual prototype,
not the functional reader UI or the agreed final navigation implementation.

On boot the bookish screen appears. **OK, UP or DOWN** switches to the other
screen. One debounced press means one change; holding does not repeat. GPIOs:
UP39, DOWN48, OK45, active low. Sleep is not implemented in this preview.
The input task samples buttons during rendering; the bounded queue holds six
presses. Each change uses HIGH quality and a full clear to avoid carrying the
previous design's residue into the comparison.

No microSD access, Wi-Fi or application settings writes. Preserve a verified
copy of the original firmware before flashing; write only the confirmed active
application slot, keeping bootloader, partition table and NVS unchanged. Retain
original bytes for every sector the preview will erase. Restore the original
reader application when the visual review is over.

Build: `pio run -e preview`. Board definition is shared with `../display-lab`;
the display dependency and platform are pinned in `platformio.ini`.

Regenerate the committed four-shade PNGs and RLE header with Pillow:

```sh
python tools/generate_preview.py --font-dir /path/to/local/windows-fonts
```

Uses local Arial, Georgia and Georgia Italic; no font binaries are redistributed.
The project logo comes from `../../source/reference/logo.png`. The artwork and
layout are generated by code. The previews are 540×960 portrait pixels, mapped
to the panel's native 960×540 layout with the reader's existing rotation.

USB (115200, DTR on / RTS off): `UI STATUS`, `UI NEXT`, `UI SHOW 0`, `UI SHOW 1`.
Status reports ready/fault, selected style, change count and raw GPIO levels.
Frame acknowledgements establish rendering completion, not optical quality or
physical button acceptance. Review both screens on the actual panel.
