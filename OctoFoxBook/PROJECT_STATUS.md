# OctoFox Book — состояние проекта

Обновлено: **11 октября 2026**.

OctoFox Book объединяет личную книжную библиотеку на своём сервере, чтение и озвучку в браузере, приложение Companion и электронную читалку AbyssBook. Этот файл описывает текущее состояние продукта; история изменений для постов — в [CHANGELOG.md](CHANGELOG.md).

Приложение Companion и прошивка в этом релизе сохраняют версию `0.9.0-rc.1` и прежние файлы; изменения прошивки `0.9.0-rc.3-dev` доступны отдельно в исходниках `main`. Новые коммиты в `main` сами по себе не обновляют установленные серверы и устройства.

## Библиотека и чтение

- Загрузка собственных книг FB2 и EPUB, личная библиотека, избранное и коллекции.
- Чтение в браузере с оглавлением, закладками и сохранением позиции.
- Серверная озвучка: русский, английский, немецкий, французский, испанский и португальский. Проверены семь голосов; выбор голоса не переводит текст книги.
- Русский и английский интерфейсы Library и серверной панели Companion.
- Аккаунты читателей, управление доступом и настройками профиля.
- Резервное копирование книг, аккаунтов и состояния чтения; проверка архива перед восстановлением и сохранение страховочной копии.

### Новое в RC3: внешние OPDS-каталоги

Каталог подключается один раз через **«Все книги → Источники»**. Его книги появляются рядом с остальными, в общей сетке обложек. Нажатие **↓** сразу отправляет выбранную книгу в загрузки; выбор сохраняется при переходе между страницами.

После скачивания книга становится доступна для открытия и появляется в «Моей библиотеке». В общем списке остаётся одна карточка, в том числе после очистки истории загрузок. Поиск и следующие страницы доступны через общий интерфейс библиотеки. Проверено на реальном каталоге Project Gutenberg и настоящем EPUB.

Поддерживаются OPDS 1.x и свободные загрузки EPUB, FB2 и архива с одним FB2. Страницы подгружаются по мере просмотра; поиск и фильтрация зависят от метаданных каталога. Значок `+` у количества означает, что доступны следующие страницы. OPDS 2, каталоги с приватными сетевыми адресами и выдача книг через покупку, заём или DRM пока не поддерживаются.

## Companion и установка сервера

- Серверная панель помогает создать аккаунты, загрузить книги, настроить доступ и привязать читалку.
- Переносимое приложение Companion для Windows, macOS и Linux ищет работающий сервер на компьютере или в локальной сети и открывает его панель.
- Отдельный Server Setup для Windows x64 и Linux x64 проверяет зависимости и содержит их автоматическую подготовку. Для Linux автоматическая подготовка Docker рассчитана на Ubuntu/Debian.
- Есть иллюстрированная инструкция по подключению домена через Cloudflare, пока на английском, и временный QR-код для проверки внешнего доступа с телефона.
- Читалка привязывается через USB с отдельным отзываемым ключом устройства. Пароль аккаунта в неё не записывается.

## AbyssBook

- Книжное оформление главной страницы, вкладок, списков и карточек книг; обложки и информация берутся из локальной библиотеки.
- Управление тремя кнопками: короткий OK открывает выбранное, двойной возвращает назад, удержание переводит к выбору вкладок по таймеру.
- Списки перелистываются целыми страницами, чтобы не сдвигать строки при каждом переходе за край экрана.
- Выбор Wi-Fi и ввод пароля на устройстве; дополнительные раскладки клавиатуры и переключение между ними.
- Английский язык по умолчанию, русский в настройках. Настройки текста, очистки экрана, сна и типа кнопки Sleep.
- Глубокий сон с сохранением состояния. Предупреждение о заряде при 15%, защитный сон при 8%; заряд оценивается по напряжению.
- Wi-Fi включается для запрошенной синхронизации и сетевых действий в настройках; обычное чтение остаётся офлайн.
- Синхронизация книг, избранного, коллекций, позиции чтения и закладок. По умолчанию выбран личный профиль целиком; можно использовать отдельную полку устройства.
- На экране синхронизации видны этап, счётчики, прошедшее время и прогресс текущего этапа или файла, когда известен его объём.

## Корпус и материалы

В репозитории есть редактируемые [STEP](STEP/), [готовый набор STL для печати](STL/print-set/), [состав электроники](ELECTRONICS.md) и [окрашенная 3D-сцена](visualization/README_RU.md). Корпус получил усиленный бортик экрана, винтовые крепления, овальный Sleep, углублённый логотип, рельефные тентакли и мелкую чешуйчатую фактуру. Расположение кнопок и форма хвата сохранены.

Производственные файлы и презентационная сцена разделены. Геометрия проверена программно; итоговую посадку и прочность деталей нужно оценивать на реальной печати. Крупные модели хранятся через Git LFS.

## Что проверено и что ещё предстоит

**Подтверждено:** чтение и серверная озвучка на тестовой установке; резервная копия и восстановление; поиск сервера приложением; привязка по USB в Windows; скачивание книги на физическую читалку; обмен позицией чтения в обе стороны и получение закладки с сайта. Новая общая OPDS-полка проверена на отдельной установке в настольном и мобильном размерах, включая поиск, скачивание и отсутствие дублей.

Последняя проверка Library: **284 Python-теста и 147 JavaScript-тестов**. Это проверки серверной и браузерной частей, а не число тестов всех компонентов проекта.

Для RC3 также прошли 15 проверок установщика и запуск Windows-пакета в режиме проверки зависимостей, без установки компонентов. Linux-пакет получил новый серверный код внутри прежнего проверенного исполняемого окружения; содержимое сверено с исходниками. Нативный запуск Linux-пакета в этом выпуске повторно не проверялся.

До 1.0 остаются:

- Стабильность и скорость синхронизации на реальном устройстве. В последней проверке прототипа воспроизводились обрывы Wi-Fi; причина ещё не установлена.
- Полный маршрут установки зависимостей на чистых ОС, включая системные разрешения и перезапуски.
- Проверка актуальных пакетов на физических Mac и USB-привязки в macOS/Linux.
- Проверка фоновой озвучки на физическом телефоне, в том числе при блокировке экрана.
- Проверка реального расхода батареи, защитного сна при разряде и переключателя Sleep с фиксацией.
- Общая пользовательская приёмка, перевод оставшейся инструкции и выпуск следующих сборок с изменениями из `main`.

Глубокий сон не является полным электрическим отключением питания: для полного выключения с запуском от подключения USB нужна доработка платы. Server Setup пока не выполняет автоматическое обновление между версиями. Резервные архивы не зашифрованы; автоматического расписания копирования пока нет.
